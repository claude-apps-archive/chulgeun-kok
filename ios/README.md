# 출근콕 iOS

SwiftUI로 만든 아이폰 버전입니다. 안드로이드 버전과 기능과 디자인을 맞췄고, iOS가 허용하지 않는 부분만 다르게 동작합니다.

## 맥에서 아이폰에 설치하기 (무료 Apple ID)

1. 맥에 **Xcode**를 설치합니다 (App Store, 무료).
2. 이 저장소를 받습니다: GitHub 저장소 화면의 **Code → Download ZIP** 후 압축을 풀거나 `git clone`.
3. `ios/ChulgeunKok.xcodeproj`를 더블클릭해 Xcode로 엽니다.
4. Xcode 메뉴 **Settings → Accounts**에서 **+ → Apple ID**로 본인 Apple ID를 추가합니다.
5. 왼쪽에서 맨 위 **ChulgeunKok** 프로젝트 → **Signing & Capabilities** 탭 → **Team**에서 본인 이름(Personal Team)을 고릅니다.
   - "bundle identifier is not available" 오류가 나면 **Bundle Identifier**를 `kr.chulgeunkok.app.내이름`처럼 바꿔 주세요.
6. 아이폰을 케이블로 맥에 연결하고, 아이폰에서 "이 컴퓨터를 신뢰" → 암호 입력.
7. 아이폰 **설정 → 개인정보 보호 및 보안 → 개발자 모드**를 켜고 재시동합니다 (처음 한 번).
8. Xcode 위쪽 기기 목록에서 내 아이폰을 고르고 ▶︎(Run)을 누릅니다.
9. 처음 실행 때 "신뢰하지 않는 개발자"가 뜨면 아이폰 **설정 → 일반 → VPN 및 기기 관리**에서 내 Apple ID를 신뢰합니다.

무료 Apple ID로 설치한 앱은 **7일 동안만** 실행됩니다. 7일이 지나면 맥에 연결하고 ▶︎를 다시 누르면 됩니다(기록은 그대로 남아요).
Apple 개발자 프로그램(연 $99)에 가입하면 1년짜리 설치나 TestFlight 배포를 쓸 수 있어요.

## 설치 후 설정

앱의 **홈 → 오른쪽 위 톱니바퀴(설정)**에서:

- 알림 허용
- 위치 **항상 허용** (처음엔 '앱을 사용하는 동안'만 고를 수 있어요. 한 번 더 누르거나 iOS 설정 > 출근콕 > 위치 > '항상')
- 정확한 위치 켜기
- **알림 테스트**로 잠금 화면과 애플워치에 알림이 오는지 확인

## 안드로이드와 다른 점

| 기능 | 아이폰 |
|---|---|
| 직장 도착·떠남 자동 감지 | ✅ 앱이 꺼져 있어도 감지 (iOS 지역 모니터링, 최대 20곳) |
| 출근·퇴근·연장 근무 버튼 | ✅ 알림을 길게 누르면 버튼, 애플워치에서도 가능 |
| 다른 앱 위 화면 가운데 팝업 | ❌ iOS가 허용하지 않음. 알림 배너로 오고, 앱을 열면 가운데 팝업 |
| 퇴근 10분 전 카운트다운 | ✅ 1분마다 알림. 다만 지난 알림이 저절로 사라지지는 않고, 앱을 열거나 퇴근하면 정리돼요 |
| 지워지지 않는 연장 근무 알림 | ❌ iOS가 허용하지 않음. 대신 퇴근할 때까지 30분마다 다시 알려요 |
| 떠난 뒤 GPS 오차 처리 | 떠나는 즉시 퇴근 기록 → 설정한 시간(기본 3분) 안에 돌아오면 되돌림 |
| 달력, 월별 급여, 급여 계산기, 직장 복사·순서 변경·삭제 | ✅ 같음 |

기록은 아이폰과 안드로이드 사이에 공유되지 않아요(각 폰에 저장).
